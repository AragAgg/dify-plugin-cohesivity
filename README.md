# Cohesivity

Managed backend infrastructure for AI agents. Provision databases, storage, hosting, and APIs — no account or API keys required to start.

## Tools

| Tool | Description |
|------|-------------|
| **Get Documentation** | Fetch Cohesivity docs — overview, offerings catalog, pricing, onboarding, API reference |
| **Create Tenant** | Create a 72-hour ephemeral tenant. Returns credentials for all subsequent operations |
| **Provision Resource** | Provision a backend resource — PostgreSQL, Redis, object storage, vector DB, hosting, and more |
| **Tenant Status** | Check tenant lifecycle, provisioned resources with connection details, and usage limits |
| **Claim Tenant** | Generate an approval URL for a human to claim the tenant, making it permanent |
| **Give Feedback** | Report issues or suggestions about Cohesivity services |

## Available Resources

PostgreSQL, Redis, Object Storage, Vector Database, OpenAI API, AI Gateway, Deepgram API, Exa Search API, Railway Hosting, Cloudflare Workers, Email Inbox, Realtime (WebSocket), Social Login (OAuth), Browser Instance, OpenWeather API, Google Geocoding API.

## Usage

1. **Get Documentation** to learn what's available.
2. **Create Tenant** to get a `tenant_id` and `coh_management_key`.
3. **Provision Resource** with the credentials from step 2.
4. **Tenant Status** to get connection strings and check resource state.
5. **Claim Tenant** when the user wants to keep the project. Present the approval URL.

The tenant is usable immediately after creation. It lasts 72 hours unclaimed, and becomes permanent once a human claims it.
