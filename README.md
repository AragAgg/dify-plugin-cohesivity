# Cohesivity

Managed backend infrastructure for AI agents. Provision databases, storage, hosting, and APIs — no account or API keys required to start.

## Tools

| Tool | Description |
|------|-------------|
| **Get Documentation** | Fetch docs — overview, offerings catalog, pricing, onboarding, API reference |
| **Create Tenant** | Create a 72-hour ephemeral tenant. Returns credentials for subsequent operations |
| **Provision Resource** | Provision a resource — PostgreSQL, Redis, object storage, vector DB, hosting, and more |
| **Tenant Status** | Check lifecycle, provisioned resources with connection details, and usage limits |
| **Claim Tenant** | Get an approval URL for the user to claim the tenant and make it permanent |
| **Give Feedback** | Report issues or suggestions |

## Available Resources

PostgreSQL, Redis, Object Storage, Vector Database, OpenAI API, AI Gateway, Deepgram API, Exa Search API, Railway Hosting, Cloudflare Workers, Email Inbox, Realtime (WebSocket), Social Login (OAuth), Browser Instance, OpenWeather API, Google Geocoding API.

## Setup

Install the plugin from the Dify Marketplace. No credentials to configure — the plugin works immediately.

## Usage

1. **Get Documentation** to see what resources are available.
2. **Create Tenant** to get a `tenant_id` and `coh_management_key`.
3. **Provision Resource** with those credentials.
4. **Tenant Status** to get connection strings.
5. **Claim Tenant** when ready to keep the project.

Tenants are usable immediately. They last 72 hours unclaimed, and become permanent once claimed.
